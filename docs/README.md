# OctoAcme Project Management Docs

This directory contains the process documentation used to manage OctoAcme projects from initiation through continuous improvement. Together, these documents provide a structured, end-to-end lifecycle: establish the project and its goals, plan scope and delivery, execute while tracking progress, manage risks and communication, release and deploy safely, and learn through retrospectives and continuous improvement. Roles and personas clarify responsibilities throughout the lifecycle.

## Process documents

- [Project Management Overview](octoacme-project-management-overview.md) — Principles, roles, artifacts, lifecycle, and communication cadence.
- [Project Initiation](octoacme-project-initiation.md) — How projects are defined, aligned, and started.
- [Project Planning](octoacme-project-planning.md) — How scope, resources, milestones, and dependencies are planned.
- [Execution and Tracking](octoacme-execution-and-tracking.md) — How delivery progress, collaboration, and outcomes are monitored.
- [Risks and Communication](octoacme-risks-and-communication.md) — How risks, decisions, escalations, and stakeholder communication are managed.
- [Release and Deployment](octoacme-release-and-deployment.md) — How changes are prepared, released, deployed, and verified safely.
- [Retrospective and Continuous Improvement](octoacme-retrospective-and-continuous-improvement.md) — How teams capture learnings and turn them into improvements.
- [Roles and Personas](octoacme-roles-and-personas.md) — Responsibilities and perspectives across the project lifecycle.

## How to use these docs

Start with the [Project Management Overview](octoacme-project-management-overview.md) for the lifecycle at a glance, then use the process-specific documents when planning or delivering work. Keep project-specific artifacts, decisions, risks, and action items up to date as the project progresses.
